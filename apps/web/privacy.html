What nostakes keeps, and what it counts

Last changed 11 November 2026.

What a room keeps

  • A room keeps the night: who joined, the names and faces you chose, every hand, and the chip counts. That is how the game carries on after a dropped phone and how it settles up. Only the people in the room see it.
  • A room deletes itself 30 days after the last thing that happened in it.

What we count

To see whether nostakes works, the server counts things as they happen:

  • a home page or invite link opened, a room opened, someone joining, a seat taken, a hand finished, a night settled up;
  • for each home page or invite link opened, which site sent the visitor, as one name from a short fixed list (x, hn, reddit, discord, google, github, bsky, linkedin, our own pages, another site, or none), never the address the visitor came from;
  • how many players a hand was dealt to, whether its deck was checked, whether it went to a showdown, how long a night lasted, and how many payments settle it, but never how much;
  • which house rules were changed, such as the ante, never to what;
  • when something goes wrong: a dropped connection, an error on a page, a deck check that failed.

Each count from a room is filed under a one-way hash of the room's internal identifier, the same for every count from that room. The room's code cannot be read back from it. Counts are kept for three months.

The random number on your device

  • With counts on, your browser makes a random number the first time you open or join a room and keeps it on this device. It is not your name and is tied to nothing else.
  • The server never stores it with a room and never shows it to anyone. It keeps only a scrambled, one-way version in the counts, so we can tell when the same group comes back to play again.

Checking the deck

  • Your device checks each hand's shuffle against public randomness from drand. When a hand was dealt without it, the page asks drand's relays for that round: api.drand.sh, api2.drand.sh, api3.drand.sh, and drand.cloudflare.com. Like any website, those relays see your device's internet address, and the request shows it came from nostakes. It carries no name, room code, or cards.

Our server's log

  • Our server writes a log line when something goes wrong, such as a fault, a step the room refused, or a failed save, and when a room starts up.
  • The lines our code writes never contain a room's code, a person's name or face, a card, a room pass, or anything anyone typed. To group one room's lines, each carries a short hash of the room's internal identifier instead of its code.
  • Cloudflare's per-request logs, which would record every web address requested and so the room code in a room's link, are turned off. Cloudflare's documentation does not say what it adds to the lines our code writes, such as the web address of the request, so we cannot promise that a line never shows one.
  • Cloudflare keeps our log lines for at most 7 days.

Your internet address

  • Cloudflare, which runs our server, sees your internet address on every request, as any website's host does.
  • To stop abuse, the server counts how many rooms you open, rooms you join, and connections you make from one internet address each minute, using Cloudflare's rate limiting. Checking whether a room still exists and sending an error report count as connections. An IPv6 address is counted by its network, the first half of the address, so one home or office network shares one count. Cloudflare's documentation does not say how long it keeps a count after its minute is up.
  • We do not store your internet address. Our code never puts it in a room, in a log line, or in our counts of what happens.

What we never record

  • Anyone's cards, names, or faces, a room's code, anything you type, or how many chips anyone won or lost.
  • No ads, no cookies, no tracking scripts from other companies, no screen recordings. Nothing is sold or shared. Everything stays in nostakes's own Cloudflare account, which runs the servers.

Turning counts off

Counts are on for this device.

Your browser sends the Global Privacy Control signal, so counts start off here unless you turn them on.

You can also use the bar chart button in the menu at the table. With counts off, this device sends no random number and no error reports, and forgets the number it had. A home page or invite link opened is counted either way, with the site that sent you: the server counts it as the page loads, before it could know this setting, and the count holds no number and no address.
