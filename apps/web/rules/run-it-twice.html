Running it twice

When players are all in before the river, deal the rest of the board twice. Each run wins half the pot.

An example

Two players are all in on the flop, with 200 in the pot.

FlopK♦︎ 8♣︎ 3♠︎
AnaK♥︎ Q♥︎
Ben8♥︎ 8♦︎

Ben has a set and Ana needs help. They run it twice, so each run is worth 100. Split the runs and they each get 100 back.

What it does to the odds

Nothing, on average. You're the same favourite on every run. It only cuts the swing.

At 80% to win a 200 pot, one run is 200 or nothing. Twice, you take both runs 64% of the time, split 32%, and lose both just 4%. Either way the hand is worth 160.

In nostakes

  • The host sets Run it up to, under All in, from 1 to 9 runs. 1 turns it off.
  • Vote: everyone still in picks, and the lowest number wins. Always most skips the vote.
  • Every run gets fresh cards, so no card shows up twice.
  • Each pot splits evenly across the runs. Odd chips go to the first runs.
  • Hands turn face up before the board runs, unless the host hides them.
